## Team Charter

From the ... which can be reviewed in ["Appendix: Team Organization"](https://embedded-systems-design.github.io/EGR304TeamTemplate/Appendix/App-Team-Org/), the team's charter formed to be (showing ASU's Charter as an Example):

> Our organization is dedicated to developing a mathematically validated, PCB schematic and layout for an advanced PSU. The team focuses purely on component selection, electrical validation, and thermal calculations. All hardware design files and technical specifications will be version-controlled in a GitHub repository, which will directly host the official datasheet website via GitHub Pages. Through a strictly peer-reviewed pull request workflow, we ensure the public-facing web documentation remains perfectly synchronized with the latest theoretical hardware architecture.

## Product Mission Statement

Describe the distilled purpose, function, or reason for your product to exist. From this form a team mission statement. Google's mission statement is:

 > To architect a highly efficient, printed circuit board (PCB) design for a Power Supply Unit (PSU) and deliver comprehensive, accessible technical documentation via a dedicated GitHub-hosted datasheet portal.
